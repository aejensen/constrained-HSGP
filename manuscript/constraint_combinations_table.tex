so that every signed profile in the second column is strictly positive
throughout $J$. For a pivot $d_{j_*}\ne0$, use

$\gamma\geq\tau_A^\varepsilon(\boldsymbol g)$ by taking the largest
displayed right-hand side. With arguments $\boldsymbol g$ suppressed,
$M_r=\max_{x\in I}\eta_r(x;\boldsymbol g)$ requires an interval maximum,
evaluated at the endpoint and stationary candidates in
\cref{cor:combinations}, whereas
$\eta_r^\pm=\eta_r(x_\pm;\boldsymbol g)$ requires only evaluation
at the left endpoint $x_-$ or right endpoint $x_+$.
All ratios
$\eta_r(x;\boldsymbol g)=-H_{r,\boldsymbol g}(w(x))/H_{r,\boldsymbol d}(w(x))$
use the same direction and coefficient map within a row.
